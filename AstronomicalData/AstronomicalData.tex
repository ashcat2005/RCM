Some important data about the Solar System 

\textbf{Sun}
\begin{itemize}
\item Mass: $ M_{\odot } = 1.99\times10^{30}$ kg
\item Mean Radius: $R_{\odot } = 696342$ km
\end{itemize}


\textbf{Earth}
\begin{itemize}
\item Mass: $M_{\oplus } = 5.972\times10^{24}$ kg
\item Mean Radius: $R_{\oplus } = 6371$ km
\end{itemize} 

Distance Sun-Earth: $1$ au $= 1.496 \times 10^8$ km
